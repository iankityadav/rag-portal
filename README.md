# RAG Testing Portal (skeleton)

This workspace contains a small preflight check skeleton and Vitest tests to align with the project's constitution.

How to run tests locally:

1. Install dependencies:

```bash
npm install
```

2. Run tests:

```bash
npm test
```

Notes:
- The preflight checks are implemented in `src/preflight/checks.ts`.
- Tests run in Node and mock browser globals. In-browser tests are planned later.
